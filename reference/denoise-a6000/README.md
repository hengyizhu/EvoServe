## 单步剖析

Kineto 采集一轮独立的单步前向。profile 为原始 eager 动作步，manual-profile 为手工路径已准备好前缀之后的动作步。六份 CSV 分别列出 CUDA kernel、ATen 算子和运行时调用，按累计时间排序。图回放的十步总时延单独测量。

| 单步 | GPU kernel 数 | 累计 kernel ms | aten::cat | aten::_to_copy | aten::copy_ | sin / cos | 高效 SDPA |
|---|---:|---:|---:|---:|---:|---:|---:|
| profile | 2258 | 8.383 | 130 | 244 | 280 | 37 / 37 | 0 |
| manual-profile | 241 | 2.765 | 0 | 2 | 2 | 0 / 0 | 18 |

原始实现用 FP32 计算 RoPE、归一化和注意力 logits，每层把前缀 K/V 与动作后缀重新拼接；时间 MLP、位置和掩码随迭代重复构造。单步里没有观察到标量回读。两份 trace 中的 cudaDeviceSynchronize 均在最后一个 ATen 算子结束以后。

手工路径将每个请求的掩码、RoPE 和前缀 KV 准备一次。每次迭代只更新动作 K/V 槽。线性层、SDPA、残差和 Euler 更新用 BF16，归一化归约保留 FP32 累加。十个时刻的调制系数依赖模型版本，在构图阶段预先生成。

用旧分段图的跨卡比例 50.62 / 72.03 粗估，新路径在 H100 为约 22.5 ms。两代 GPU 的带宽和 SDPA 后端不同，须用 H100 实测。
